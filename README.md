# Journal

A React journaling app with dated entries, mood tracking, tags and search, and writing prompts (built-in list plus prompts generated by Claude).

## Setup

Requires Node 20.6+ and a running PostgreSQL server.

    npm install
    cp .env.example .env    # add your Anthropic API key and DATABASE_URL
    createdb journal        # or create the database however you prefer

Then run the API and the frontend in two terminals:

    npm run server          # Express API on http://localhost:3001
    npm run dev             # Vite frontend

The server creates the `entries` table on startup if it doesn't exist (see `server/schema.sql`).
The app works without an Anthropic key; only the "Ask Claude for one" button needs it.

## Where things live

- `server/` is the Express API. `index.js` has the routes (`GET/POST /api/entries`, `PATCH/DELETE /api/entries/:id`), `db.js` the connection pool, `schema.sql` the table.
- `src/storage.js` is the frontend's API client for those routes.
- `src/prompts.js` holds the built-in prompt list and the Claude API call. The model name is a constant at the top of the API section.
- `vite.config.js` proxies `/api/entries` to the Express server, and proxies `/api/anthropic` to the Anthropic API and adds your key on the dev server, so the key never reaches the browser. This proxy only exists in `npm run dev`; for a production build you'll need an equivalent endpoint on your own backend.
- `src/moods.js` defines the five mood levels.
